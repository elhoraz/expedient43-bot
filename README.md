# Expedient 43 - WhatsApp Cloud Bot Gateway 🤖

Official 24/7 Self-Hosted WhatsApp Cloud Gateway & Multimodal AI for Expedient Generation 43 (Angkatan 2025).

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/elhoraz/expedient43-bot)

## Fitur Unggulan
- **100% Baileys Self-Hosted** (Tanpa pihak ketiga berbayar / Fonnte / Telegram).
- **Gemini Multimodal AI**: Teks, Gambar, Stiker (.webp), Voice Note, dan Video Note.
- **Supabase Cloud Session Auto-Sync**: Sesi login otomatis dipulihkan dari Supabase Storage (`wa-session-backup`).
- **HTTP Health Check**: Endpoint `/health` aktif untuk menjaga server tidak tidur melalui keep-alive ping.
